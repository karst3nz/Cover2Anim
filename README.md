# Cover2Anim

Аддон для PulseSync, который заменяет статичный фон полноэкранного плеера на плавную анимацию цветных blob'ов, чьи оттенки подстраиваются под обложку играющего трека.

## Что делает

- Скрывает стандартный фон `FULLSCREEN_PLAYER_MODAL` (псевдоэлементы `::before`/`::after`).
- Вставляет в модалку `<canvas class="betterplayer-canvas-bg">` под остальными элементами управления.
- Достаёт полноразмерную обложку из `<img data-test-id="ENTITY_COVER_IMAGE">` (самый большой URL из `srcset`, обычно 2x версия) через отдельный CORS-`Image`, чтобы canvas не был tainted.
- Рисует 6–18 размытых blob'ов, которые дрейфуют, пульсируют и плавно перетекают в новые цвета при смене трека.
- Следит за сменой обложки через `MutationObserver` + поллер каждые 1000 мс и автоматически перестраивает палитру.

## Настройки

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `enabled` | bool | `true` | Включает/выключает фоновую анимацию. |

Остальные параметры (радиус, скорость, блюр, яркость, число blob'ов, время перехода палитры) зашиты в код как разумные дефолты.

## Как берётся палитра

1. Из `srcset` обложки выбирается самый большой URL (дескриптор с шириной или плотностью `2x`).
2. Картинка рисуется на offscreen-канвас в полный размер (`naturalWidth × naturalHeight`).
3. По канвасу проходит сетка шагов с лимитом ~4000 сэмплов, каждый сэмпл = один пиксель с весом `step²`.
4. Сэмплы перемешиваются (Fisher-Yates) и кластеризуются жадно с порогом RGB `d² < 4900` (≈70 на канал).
5. Берётся топ-6 кластеров, отсортированных по суммарному весу.

Доминирующий цвет для фона считается отдельно как средневзвешенный RGB по всей картинке (не по кластерам), чтобы случайный акцент в углу не перекрашивал фон.

## Затемнение фона

Доминирующий цвет проходит через `darken(hex, BG_LIGHTNESS=0.18)` — RGB → HSL → фиксируем L=0.18 → RGB → hex. Сохраняются оттенок и насыщенность обложки, убирается только яркость. UI плеера поверх остаётся читаемым.

## Плавность перехода

При смене трека:

- Палитра блендится **волной**: `colorOffset = (i / count) · 0.8` распределяет старт бленда по blob'ам.
- Каждый blob блендит через `smoothstep` (`t² · (3 − 2t)`) за `PALETTE_FADE_MS = 1000` мс.
- Фон тоже блендит за то же время через ту же smoothstep-кривую.
- Если доминирующий цвет не меняется — фон не дёргается.

## CORS и debounce

- В `addon.config.mjs → allowedUrls` прописано `https://avatars.yandex.net` (и `avatars.mds.yandex.net`).
- Каждая смена `src` обложки дебаунсится на `COVER_DEBOUNCE_MS = 400` мс — при карусели превьюх грузится только последняя обложка, без шторма HTTP-запросов.
- Защита от гонки: `coverRequestId` инкрементируется на каждый `loadCover`, устаревшие `Image()` отбрасывают свой `onload`/`onerror`.

## Сравнение палитр

`pollCover` раз в 1000 мс проверяет, изменилась ли палитра, сравнивая её с последними 3 (с допуском `d² < 1500` на цвет, ≈28 на канал) и с `basePalette`. Совпадение → `palette unchanged`, иначе — плавный `reapply`.

## Resize без мерцания

`ResizeObserver` перед изменением `canvas.width/height` сохраняет `ImageData` текущего кадра и растягивает его на новый размер через временный canvas + `drawImage` с `imageSmoothingEnabled`. Чёрного мерцания между resize и следующим RAF не видно.

## Файлы

- `script.js` — собранный бандл из `src/main.ts`.
- `script.css` — стили скрытия стандартного фона и позиционирования canvas.
- `handleEvents.json` — схема настроек.
- `metadata.json` — метаданные аддона, генерируются при сборке.
- `pulsesync.settings.json` — пользовательские значения, создаётся PulseSync, не входит в архив публикации.

## Известные ограничения

- Если обложка отдаётся без `Access-Control-Allow-Origin`, палитра не извлекается — работает fallback на радугу.
- На очень светлых/однотонных обложках blob'ы будут в пастельных/белых тонах — это честная палитра, не баг.
- Полное отключение аддона вступает в силу только после повторного открытия полноэкранного плеера.
