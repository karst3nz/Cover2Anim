# Cover2Anim

Аддон для PulseSync, который заменяет статичный фон полноэкранного плеера на плавную анимацию цветных blob'ов, чьи оттенки подстраиваются под обложку играющего трека.

## Что делает

- Прячет стандартный фон плеера и рисует вместо него анимированные цветные пятна на canvas.
- Достаёт палитру из обложки играющего трека — фон и blob'ы плавно меняют цвет вместе со сменой музыки.
- Blob'ы дрейфуют, пульсируют и перетекают друг в друга при смене трека, без резких скачков.
- UI плеера всегда остаётся поверх анимации и читаем — фон затемнён под текст.

## Настройки

- **Включить аддон** — вкл/выкл фоновую анимацию (по умолчанию включено).

## Известные особенности

- На очень светлых или однотонных обложках анимация будет в пастельных тонах — это отражение реальной палитры обложки, а не баг.
- Полное отключение аддона вступает в силу после повторного открытия полноэкранного плеера.
